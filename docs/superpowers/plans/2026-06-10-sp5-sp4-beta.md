# SP5 + SP4 + Suggestions UI — Beta Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the commander suggestion engine (SP5), the typed relationship explorer (SP4), and a
suggestions panel UI — verified end-to-end with Playwright — bringing the deckbuilder to Beta.

**Architecture:** SP5 is an online read-time engine in `backend/app/suggest.py` that blends EDHREC
commander synergy, co-occurrence lift, structural synergy, and engine completion over candidates
generated from indexed neighbor reads. SP4 evolves `CardLookupPanel` into a `RelationshipExplorer`
with four typed axes backed by SP1/SP3 tables. A new `SuggestionsPanel` surfaces SP5 in the UI.

**Tech Stack:** FastAPI + sqlite3 (read-only), Next.js 14 + zustand + react-query, Playwright MCP.

**Senior redesign deltas vs. the junior specs (the why):**
1. **Accumulation scoring** — the SP5 spec's `mean(liftnorm(c,d) for d in D)` naively costs
   O(|D|²·k) pair queries per request. Instead: one pass over each deck card's neighbor list,
   accumulating per-candidate sums (`cooc_sum`, `struct_sum`), divided by |D| at the end.
   O(|D|·k), no per-pair queries. Missing pairs contribute 0 — same math, tractable.
2. **In-memory engines index** — `Store.deck_engines()` already full-scans + JSON-parses all
   35,028 `engines` rows per request; SP5's engine-completion would inherit that. Load engines
   once at startup with an inverted `member_id → [engine_idx]` index; `deck_engines()`,
   `engines_with()`, and SP5 all read it.
3. **Suggestions UI is in scope** — SP5 backend-only + SP4 explorer still leaves the flagship
   feature invisible. A `SuggestionsPanel` (header button, tier badge, reasons, add-to-deck) is
   part of Beta.
4. **Name resolution** — `edhrec_metrics` is name-keyed; cards.json names include `A // B`
   double-faced forms. Build `name→id` over full names AND front faces (lowercased).
5. **Similarity ordering** — `card_relationships` has no similarity index; per-card row sets are
   small (top-K per card), so fetch by `a=?`/`b=?` (indexed) and sort in Python.
6. **Banlist** — cards.json has no `legalities`; static Commander banlist set in `suggest.py`,
   plus exclude basic lands from suggestions (suggesting Swamp is noise).
7. **Synergy orientation for suggestions** — use `max(synergy_ab, synergy_ba)` per edge: for
   "should I add c", either direction of enablement is a reason to add.

### Task 2: suggest.py — the engine

**Files:** create `backend/app/suggest.py`

Core (complete logic — implement exactly):

```python
WEIGHTS = {"edh": 0.45, "cooc": 0.30, "struct": 0.15, "engine": 0.10}
NEIGHBOR_K = 30
LIFT_K = 0.25  # mirror scoring/cooccurrence/fuse.py lift_to_norm

def lift_to_norm(lift): return 0.0 if lift <= 1.0 else min(1.0 - math.exp(-LIFT_K * (lift - 1.0)), 0.999999)

def recommend(store, commander_id, deck_ids, limit=12, explain=False):
    cmd = store.get(commander_id)  # 400 upstream if None or not legendary creature/planeswalker
    ci = set(cmd["color_identity"])
    deck_set = set(deck_ids) | {commander_id}
    members = list(deck_set)              # commander counts as a deck member
    n = len(members)
    acc = defaultdict(lambda: {"edh": 0.0, "cooc": 0.0, "struct": 0.0, "engine": 0.0,
                               "cooc_hits": 0, "struct_hits": 0, "engines": []})
    edh = store.edhrec_for(commander_id)
    tier = "edhrec" if edh else "cooccurrence"
    for cid, (syn, _inc) in edh.items():
        acc[cid]["edh"] = max(0.0, min(1.0, syn))
    for d in members:
        for other, lift, _j in store.cooccurrence_neighbors(d, NEIGHBOR_K):
            a = acc[other]; a["cooc"] += lift_to_norm(lift); a["cooc_hits"] += 1
        for other, syn in store.synergy_neighbors(d, NEIGHBOR_K):
            a = acc[other]; a["struct"] += syn; a["struct_hits"] += 1
    for d in members:                      # engine completion: all-but-one present
        for eng in store.engines_with(d):
            missing = [m for m in eng["members"] if m not in deck_set]
            if len(missing) == 1:
                a = acc[missing[0]]
                bonus = 1.0 if eng["asserted"] else 0.3
                if bonus > a["engine"]: a["engine"] = bonus; a["engines"] = [eng]
    # filter + score
    w = dict(WEIGHTS)
    if not edh: w["edh"] = 0.0
    total_w = sum(w.values())
    scored = []
    for cid, a in acc.items():
        card = store.get(cid)
        if card is None or cid in deck_set: continue
        if not set(card["color_identity"]) <= ci: continue
        if card["name"] in BANLIST or "Basic" in card["type_line"]: continue
        s = (w["edh"]*a["edh"] + w["cooc"]*(a["cooc"]/n) + w["struct"]*(a["struct"]/n)
             + w["engine"]*a["engine"]) / total_w
        scored.append((s, cid, a))
    scored.sort(key=lambda t: (-t[0], t[1]))
    if len(scored) < limit:                # tier 3 fill
        tier = tier if scored else "color_staple"
        ... append store.staples_for_colors(ci, ...) not already present,
            score = small frequency-normalized value, reason "format staple in your colors"
    return {"tier": tier, "suggestions": [... top limit, reasons iff explain ...]}
```
