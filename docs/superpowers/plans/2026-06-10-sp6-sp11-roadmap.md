**Why:** the deck lives only in zustand memory — a refresh loses everything. Table stakes.

## 6.1 Storage: `data/userdecks.sqlite` (gitignored, read-WRITE)

Owned by `backend/app/decks.py::UserDecks` (NOT by `Store`, which stays read-only).
One module-level instance via `get_userdecks()` mirroring `get_store()`'s `lru_cache` pattern.

```sql
PRAGMA journal_mode=WAL;
CREATE TABLE IF NOT EXISTS decks (
    id           TEXT PRIMARY KEY,          -- uuid4().hex
    name         TEXT NOT NULL,
    commander_id TEXT,                      -- card id or NULL
    created_at   TEXT NOT NULL,             -- datetime.now(timezone.utc).isoformat()
    updated_at   TEXT NOT NULL
);
CREATE TABLE IF NOT EXISTS deck_cards (
    deck_id  TEXT NOT NULL REFERENCES decks(id) ON DELETE CASCADE,
    card_id  TEXT NOT NULL,
    zone     TEXT NOT NULL DEFAULT 'Utility',
    quantity INTEGER NOT NULL DEFAULT 1,
    PRIMARY KEY (deck_id, card_id)
);
```
- Open ONE connection in `UserDecks.__init__` with `check_same_thread=False` and a
  `threading.Lock` around writes (FastAPI sync endpoints run in a threadpool).
- `PRAGMA foreign_keys=ON` per connection (SQLite default is off).
- Save is **full replace**: `DELETE FROM deck_cards WHERE deck_id=?` then executemany INSERT —
  no diffing. Decks are ≤ ~110 rows; replace is simpler and atomic inside one transaction.

`UserDecks` methods (exact signatures; all return plain dicts, routers do model validation):

## 6.3 Importer: `backend/app/importer.py::parse_decklist(store, text) -> tuple[list[dict], list[str]]`

Returns `(cards, unresolved)` where `cards = [{card_id, zone, quantity}]` (zone via the
SP8 `category_of` → zone name mapping below) and `unresolved` = original lines that didn't
resolve. Accept all of these real-world line shapes (Moxfield / Archidekt / MTGO / MTGA):

```
1 Sol Ring                      # plain count
1x Sol Ring                     # x-suffixed count
Sol Ring                        # bare name (count 1)
1 Sol Ring (C21) 263            # set + collector number suffixes
1 Sol Ring (C21) 263 *F*        # foil marker
1 Sol Ring #!Commander          # archidekt category hash-tag
// Lands                        # category comment   -> ignore line
## Ramp (10)                    # moxfield category  -> ignore line
SB: 1 Sol Ring                  # sideboard          -> ignore line
Commander: The Ur-Dragon        # commander designation
1 The Ur-Dragon *CMDR*          # moxfield commander marker
Deck                            # arena section headers ("Deck","Sideboard","Commander","About")
```

Exact algorithm (implement as written):
```python
_LINE = re.compile(r"^\s*(?:(\d+)\s*[xX]?\s+)?(.+?)\s*$")
_STRIP_SUFFIX = re.compile(r"\s*(\((\w{2,6})\)\s*[\w-]*|\*[A-Za-z]+\*|#!?[\w\s-]+|\[\w+\])\s*$")

def parse_decklist(store, text):
    cards: dict[str, dict] = {}          # card_id -> row (dedupe; sum quantities)
    unresolved: list[str] = []
    commander_id: str | None = None
    section_sideboard = False
    for raw in text.splitlines():
        line = raw.strip()
        if not line or line.startswith(("//", "#", "##")):
            continue
        low = line.lower()
        if low in ("deck", "mainboard", "about"):
            section_sideboard = False; continue
        if low in ("sideboard", "maybeboard", "considering"):
            section_sideboard = True; continue
        if low.startswith("sb:"):
            continue
        if section_sideboard:
            continue
        is_cmdr = False
        if low.startswith("commander:"):
            line = line.split(":", 1)[1].strip(); is_cmdr = True
        if "*cmdr*" in low:
            line = re.sub(r"\*cmdr\*", "", line, flags=re.I).strip(); is_cmdr = True
        m = _LINE.match(line)
        qty = int(m.group(1)) if m.group(1) else 1
        name = m.group(2)
        while True:                       # strip stacked suffixes: "(C21) 263 *F*"
            stripped = _STRIP_SUFFIX.sub("", name)
            if stripped == name: break
            name = stripped
        cid = store._name_to_id.get(name.lower())
        if cid is None:
            unresolved.append(raw.strip()); continue
        card = store.get(cid)
        basic = "Basic" in (card.get("type_line") or "")
        qty = qty if basic else 1         # singleton format
        row = cards.setdefault(cid, {"card_id": cid, "zone": _zone_for(card), "quantity": 0})
        row["quantity"] = row["quantity"] + qty if basic else 1
        if is_cmdr:
            commander_id = cid
    return list(cards.values()), unresolved, commander_id
```
(`_zone_for(card)` maps `category_of` → frontend zone names:
`land→"Lands", ramp→"Ramp", card_draw→"Card Draw", removal→"Removal", board_wipe→"Board Wipes",
counters→"Counters", tokens→"Tokens", synergy→"Utility"`; a card whose type_line contains
"Legendary Creature" AND is the designated commander → zone `"Commanders"`.)
If no explicit commander designation: the import endpoint sets `commander_id` to the first
card whose zone would be `"Commanders"` (a Legendary Creature), else None.

## 6.4 Export format (`/decks/{id}/export`)

```
Commander
1 The Ur-Dragon

Lands
1 Command Tower
8 Mountain
...

Ramp
1 Sol Ring
...
```
Group by zone in the fixed zone order from `zones.ts` (`Commanders` rendered as `Commander`);
within a zone sort by name; format `"{quantity} {name}"`. This format re-imports cleanly
through `parse_decklist` (section headers are bare words → treated as unresolved-free ignores
because they fail name resolution — NO: bare zone names like "Lands" would land in
`unresolved`. Therefore prefix every zone header with `// ` in the export:
`// Lands`. The commander line uses `Commander: The Ur-Dragon` syntax instead of a header.
**Round-trip test below depends on this.**)

# SP7 — Commander Spellbook combo intelligence

**Why:** the engines table has only 96 asserted combos (mined). Commander Spellbook is the
canonical open EDH combo database (~30–40k curated variants). Importing it upgrades combo
completion (SP5), the explorer Combos tab (SP4), deck combo detection, and SP9 graph edges
from "toy" to "authoritative".

## 7.1 Acquisition: `tools/import_spellbook/runner.py` (scaffolded; stdlib-only)

- **Source (verified 2026-06-10):** REST `https://backend.commanderspellbook.com/variants/?limit=100`
  with cursor pagination — response `{count, next, previous, results}`; follow `next` URLs until
  null. (Bulk alternative `https://json.commanderspellbook.com/variants.json` exists but is
  517 MB / can't be stream-parsed with stdlib json — do NOT use it.)
- **Verified variant shape** (fields confirmed against the live API):
  - top level: `id, of, uses, notes, prices, status, spoiler, identity, includes, produces,
    requires, legalities, popularity, bracketTag, description, manaNeeded, variantCount,
    manaValueNeeded, easyPrerequisites, notablePrerequisites`
  - `uses[]`: `{card: {id, name, oracleId, typeLine, ...imageUri*}, quantity, zoneLocations,
    mustBeCommander, exileCardState, libraryCardState, graveyardCardState, battlefieldCardState}`
  - `produces[]`: `{feature: {id, name, status, uncountable}, quantity}`
  - `legalities`: booleans incl. `commander`
- Protocol: urllib `Request` with header `User-Agent: simmander-deckbuilder/1.0`; throttle
  **0.5 s between requests**; on HTTP 429/5xx retry with backoff 5s→10s→30s (3 tries) then abort
  with a resumable state. Write each variant as one JSON line to
  `data/spellbook_raw.jsonl` (gitignored). **Resume:** persist the last `next` URL to
  `data/spellbook_state.json` after every page; `--resume` starts from it and appends.
  CLI: `python tools/import_spellbook/runner.py [--resume] [--limit-pages N]` with progress
  prints every 10 pages. Expect ~400 pages / ~4 minutes.

## 7.2 Load: `tools/import_spellbook/load_spellbook.py` (scaffolded) → `data/spellbook.sqlite`

## 7.4 SP5 scoring integration (`suggest.py`)

In `recommend()`'s member loop, after the engines pass, add a spellbook pass:
```python
SPELLBOOK_BONUS = 1.2          # outranks mined asserted combos (1.0)
for d in members:
    for combo in store.spellbook_with(d):
```

# SP8 — Deck Doctor: type-aware completion + cut suggestions

**Why:** SP5 ranks next-cards but ignores deck composition (it would happily suggest 60
creatures). The Doctor completes a deck to 100 with a sane mana base and quota-aware picks, and
tells you what to cut.

## 8.1 Composition template (module constants in `backend/app/doctor.py`)

```python
TEMPLATE = {            # target counts for a 100-card deck (commander included in total)
    "land": 37, "ramp": 10, "card_draw": 10, "removal": 9, "board_wipe": 3,
    # remaining ~30 slots: "synergy" (uncapped — absorbs counters/tokens/synergy)
}
NONBASIC_LAND_CAP = 12   # staple nonbasics; rest of land quota = basics by pip ratio
RESCORE_EVERY = 10       # greedy batch size before re-running recommend()
```
Categories via `category_of` (§ cross-phase). `counters`/`tokens` count toward `synergy`'s
budget (they're strategies, not quotas).

## 8.2 `complete_deck(store, commander_id, deck_ids, template=TEMPLATE) -> dict` (scaffolded)

Deterministic greedy with quota boosts; returns
`{"added": [{card_id, zone, quantity, reason}], "final_size": int}`.

```
1. Validate commander (reuse suggest.is_commander; 400 upstream otherwise).
2. counts = Counter(category_of(store.get(cid)) for cid in deck_ids)   # commander excluded
3. NONLAND LOOP:
   pool = recommend(store, commander_id, current_ids, limit=120, explain=False)["suggestions"]
   pool_iter = iter of (score, card) excluding lands, sorted as returned
   repeat: deficit(cat) = max(template.get(cat, 0) - counts[cat], 0)
       nonland_target = 100 - 1 - template["land"]          # = 62
       if nonland_count >= nonland_target: break
       pick the pool entry maximizing  score * (1.5 if deficit(category_of(card)) > 0 else 1.0)
           — implement as: first pass over remaining pool for max boosted score (pool ≤ 120, fine)
       if pool exhausted: extend pool from store.staples_for_colors(ci, exclude=current)
           (score = 0.01, reason "staple fill")
       add card; counts/current_ids update; every RESCORE_EVERY adds → refresh pool
       reason = f"{category_of} (deficit fill)" if boosted else "best blend score"
4. LANDS:
   a. nonbasics: store.staples_for_colors(ci) filtered to "Land" in type_line, top
      NONBASIC_LAND_CAP by frequency, reason "land staple".
   b. basics: pips = Counter of colored mana symbols in mana_cost of ALL nonland cards now in
      deck (regex r"\{([WUBRG])(?:/[WUBRGP])?\}" — count the FIRST color of hybrids; ignore
      phyrexian halves). slots = template["land"] - nonbasics_added.
      per-color = floor(slots * pips[c]/total); distribute remainder by largest fractional
      part, ties in WUBRG order. Colorless-identity commander → all Wastes; missing basic name
      resolution must not crash (resolve "Plains","Island","Swamp","Mountain","Forest","Wastes"
      via _name_to_id; skip colors with 0 pips unless slots remain after distribution).
      Emit ONE row per basic with quantity=N (zone "Lands").
5. Determinism: every selection tiebreaks (-score, card_id). No randomness anywhere.
```

## 8.3 `suggest_cuts(store, commander_id, deck_ids, limit=10) -> list[dict]` (scaffolded)

Contribution score per in-deck nonland card (reverse of SP5, same accumulation trick over the
REST of the deck):
```
contrib(c) = w_edh·edhrec_synergy(cmd, c)
           + w_cooc·mean liftnorm(c, d) over d in deck\{c}
           + w_struct·mean synergy(c, d) over d in deck\{c}
           + w_engine·(1.0 if c is in any COMPLETE spellbook combo or asserted engine within the deck else 0)
```
Implementation: ONE accumulation pass over all deck members' neighbor lists building
`pair_sum[(a_in_deck)]` — when iterating member d's neighbors, if `other` is ALSO in the deck,
add to BOTH ends' running sums. Then per card divide by (n-1). Engines/spellbook: mark every
member of every complete combo. Returns the `limit` lowest-contribution cards as
`[{card: Card, contribution: float, reasons: [Reason]}]` ascending (worst first), with reasons
explaining what's MISSING (e.g. `{"signal": "cooccurrence", "value": 0.01, "detail": "rarely
played with the rest of this deck"}`). Never include: the commander, lands, or any member of a
complete combo (those have engine=1 anyway — exclude explicitly for safety).

# SP9 — Synergy graph view

**Why:** the explorer shows one card's neighborhood as lists; the graph shows the DECK as a
structure — clusters (token engine, reanimator package), bridges, and isolated cards (cut
candidates) become visible at a glance.

## 9.1 Backend: `POST /deck/graph` (scaffolded, 501) → `GraphResponse`

Body `DeckRequest` (commander included as a node). Build edges ONLY among deck cards:
```python
def deck_graph(store, ids: list[str]) -> dict:
    # nodes
    nodes = [{"id": cid, "name": card.name, "ier": card.ier,
              "category": category_of(card),
              "image": card.image_uris.normal or None} for resolvable cid]
    # edges — one accumulation pass, same trick as suggest.py:
    #   for each member d: cooccurrence_neighbors(d, 50) & synergy_neighbors(d, 50);
    #   keep pairs where other ∈ deck. Thresholds: lift >= 2.0  /  synergy >= 0.30.
    #   weight = lift_to_norm(lift)  or  synergy value  (both ∈ [0,1)).
    # spellbook + asserted engines: for every COMPLETE combo in the deck, add all member
    #   pairs with kind "combo", weight 1.0 (these override same-pair edges of other kinds).
    # dedupe by unordered pair keeping max weight per kind priority combo > synergy > cooccurrence;
    # cap: per node keep top 8 edges by weight (apply after dedupe: sort all edges by weight
    #   desc, keep edge if either endpoint has < 8 kept edges so far).
    return {"nodes": nodes, "edges": [{"a": ..., "b": ..., "kind": ..., "weight": ...}]}
```

# SP10 — Eval harness & weight tuning

**Why:** SP5's weights (0.45/0.30/0.15/0.10) are hand-tuned. We have 4,255 REAL decks — use
them as ground truth: hide cards from a real deck, ask the engine to reconstruct, measure.
This turns "finds synergy before humans" into a number.

## 10.1 `scoring/eval_suggest.py` (scaffolded; stdlib-only, imports backend.app via sys.path)

```
python scoring/eval_suggest.py --decks data/decks.sqlite --holdout 10 --limit 50 \
       [--weights 0.45,0.30,0.15,0.10] [--grid] [--split test|train|all] [--max-decks 500]
```
Protocol (implement exactly):
1. Load the backend Store ONCE (`sys.path.insert` backend dir; `from app.store import get_store`).
   Set env overrides before import if needed. This reuses the real engine — no reimplementation.
2. Eligible decks: commander name resolves via `_name_to_id` AND ≥ 30 mainboard cards resolve.
   Split by `hash(deck_id) % 2`: 0 = train, 1 = test (stable across runs).
3. Per deck: `rng = random.Random(deck_id)` (string seed — deterministic). Sample
   `holdout=10` resolvable nonland, non-commander cards as the hidden set H. Input deck =
   resolved cards minus H.
4. Call `app.suggest.recommend(store, cmd_id, input_ids, limit=50)`; let S = suggestion ids in
   rank order. Metrics per deck:
   - `recall@k` for k ∈ {10, 25, 50}: `|H ∩ S[:k]| / |H|`
   - `MRR`: mean over h ∈ H of `1/rank(h in S)` (0 if absent)
5. Aggregate: mean over decks; report per-tier breakdown (edhrec vs cooccurrence) and a
   baseline row: **popularity baseline** = staples_for_colors(commander CI) ranking (same
   metrics) — the engine must beat it decisively or something is wrong.
6. `--grid`: weight search ON THE TRAIN SPLIT over the simplex grid
   `w_edh ∈ {0.3,0.4,0.5,0.6}, w_cooc ∈ {0.1,0.2,0.3,0.4}, w_struct ∈ {0.05,0.15,0.25}`,
   `w_engine` fixed 0.10, skip combos whose sum ≠ 0.9..1.1 after adding w_engine, renormalize.
   Patch `app.suggest.WEIGHTS` per combo (module global — set & restore). Rank by recall@25.
   Print a table; print the winner's TEST-split metrics last.
7. Output: aligned text table to stdout + JSON dump to `data/eval_results.json` (gitignored).

**⚠️ LEAKAGE CAVEAT (print it in the report header, verbatim):** "co-occurrence and EDHREC
tables were built FROM these same decks; absolute numbers are optimistic. Valid for RELATIVE
comparison (weights A vs B, engine vs baseline) only."
(A clean-room variant — rebuild cooccurrence excluding eval decks — is documented as a
follow-up, NOT in scope.)

## 10.2 Apply the winner

If grid search finds a config beating the defaults by ≥ 2 points recall@25 on TEST, update
`suggest.WEIGHTS` (and the SP5 golden tests if thresholds shift — they assert ordering/shape,
not absolute scores, so they should survive).
